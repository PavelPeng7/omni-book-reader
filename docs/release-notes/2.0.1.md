# 2.0.1 — 书库初始化失败恢复

修复首次加载失败后反复弹出“书库未成功加载，暂停写入以保护原文件”、刷新无法恢复的问题。

- 加载失败时保留原始错误，停止向存储提交默认状态，避免后续保存请求反复触发二次保护提示。
- 首次加载失败后在工作区就绪时重试；也可运行“刷新书库”重新加载，无需再次重启。
- 恢复成功后读取已保存的设置与书籍状态，并恢复阅读页；并发恢复请求共享一次加载。
- 卸载失败初始化的插件时不再尝试保存默认状态；初始化原始异常会记录到控制台，方便继续诊断。

**升级说明**：2.0.0 用户可直接升级，书库格式不变，不需要重新导入或迁移书籍。更早版本仍遵循 2.0.0 的存储兼容说明：旧阅读数据不会自动迁移。请确保同一 Vault 只有一份有效的 `omni-book-reader` 插件清单，升级后重新加载插件或重启 Obsidian。

**验证范围**：lint、类型检查、133 项自动化测试、生产构建及发布资源校验通过；另行通过实际书库回读和 EPUB 解析检查。原生会话完整初始化重试已成功，修复后的原生冷启动和完整桌面/移动端验收仍待确认。

---

Fix repeated unloaded-library notices after failed initialization. Failed loads preserve their original error and block fallback saves. Initialization retries when the workspace becomes ready; manual library refresh can retry later. Successful recovery restores persisted settings and reader tabs. Concurrent recovery loads are shared, and failed initialization is not flushed on unload.

The managed-library format is unchanged from 2.0.0; no reimport or migration is required for existing managed books. Earlier legacy formats are still not migrated automatically. Reload the plugin after updating. Automated checks and real-library parsing pass; patched native cold-start and full desktop/mobile acceptance remain pending.
