# 2.0.0 — 独立书库与文库刷新修复

这是不兼容旧存储格式的主要版本更新。升级前请备份 Vault 和旧插件数据。

- 书籍、进度、书签、批注、封面和导出集中存放在 Vault 内可见的 `My Reader/`，每本书使用独立文件夹；可在设置中整体搬迁书库。
- 从文库或文件菜单显式导入 EPUB。导入会移动原文件；同内容重复导入复用已有书籍，并保留重复来源。
- 每书使用固定身份和相对资源路径，支持整书文件夹移动、改名和复制到另一 Vault 的书库；导出保留受管块外的手写内容。
- 修复“我的文库”因重复刷新、无关文件事件或标签切换而反复重建封面的闪烁，保留无变化页面的搜索焦点和滚动位置。

**升级说明**：旧 `data.json`、进度、批注、导出和封面缓存不会自动读取、迁移或清理。重新导入 EPUB 后使用新格式；旧阅读状态不会自动延续。此前已使用新书库格式的数据可继续使用。删除书籍会确认并回收整个书籍文件夹，包括其中的手写文件。多设备并发修改不自动合并，请先完成同步再切换设备。

**验证范围**：自动化检查覆盖书库文件操作、故障保护、导出内容保留与文库刷新。原生 Obsidian 桌面/移动端的完整验收仍待完成，现有 EPUB fixture 测试仍跳过。

---

Major storage change: a configurable visible library now owns each book's EPUB, state, covers and exports. Imports move the source EPUB; identical content reuses an existing book. Unchanged bookshelf refreshes preserve loaded covers, search focus and scroll position.

Legacy state is neither loaded nor migrated automatically. Back up your Vault and old plugin data before upgrading, then import EPUBs into the new library. Existing data in the new managed-library format remains usable. Book deletion recycles the entire book folder, including handwritten files. Concurrent edits across devices are not merged. Automated checks pass; native desktop/mobile acceptance remains pending.
